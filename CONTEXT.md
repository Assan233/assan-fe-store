# Glossary

- **应用库**：The authenticated personal workspace that gathers small everyday utilities in one place.
- **应用 / 工具**：A single utility offered by the library. A card marked **功能预览** is a catalog entry only; it is not an executable tool.
- **工作空间**：The signed-in user's private view of the application library and account settings.
- **账户**：A username and password used to access a personal workspace.
- **会话**：A time-limited authenticated browser visit associated with an account.
